A Universal Manipulation Interface for the ORCA hand

A hand-held device that uses the ORCA hand's kinematics, so people can show manipulation tasks by hand. It records joint angles, touch and pose so the robot can learn the same tasks.

Ubuntu 26.04 ROS 2 Jazzy · RoboStack pixi Python ORCA v2 · right hand rosbag2 / MCAP
View on GitHub Getting started

System overview

The UMI uses the same kinematics as the ORCA hand. Our own sensors and pose estimation write into one time-synced recording, which is then exported into a training dataset.

Subsystems

Each subsystem is its own ROS 2 package. You can develop, test and launch each one alone.

Shared kinematics planned

The ORCA hand URDF and STL meshes. This is the one source of truth for joint names, limits and frames.

src/external/orcahand_description · upstream submodule

Joint sensing planned

Reads our own joint sensors and publishes sensor_msgs/JointState, with joint names mapped to the URDF.

src/rwrumi_joint_sensors

Tactile sensing planned

Reads our own tactile sensors and publishes a custom tactile array message with hardware timestamps.

src/rwrumi_tactile · msgs in rwrumi_interfaces

Pose estimation hardware TBD

Estimates the global pose of the UMI in the world frame and the relative pose between the UMI and the object. Both go out on /tf.

src/rwrumi_pose

Recording planned

Records all streams, time-synced, into rosbag2 (MCAP), one bag per demonstration episode.

src/rwrumi_recorder

Dataset export planned

Converts the recorded bags into per-episode HDF5 files for policy learning.

src/rwrumi_recorder

Getting started

The workspace isn't set up yet. These are the intended steps once it is.

# 1. Install pixi (once per machine) – no system ROS install needed
curl -fsSL https://pixi.sh/install.sh | sh

# 2. Clone including the ORCA submodule
git clone --recursive https://github.com/erhell/RWRUMI.git
cd RWRUMI

# 3. Exact environment from pixi.lock (ROS 2 Jazzy + all dependencies)
pixi install

# 4. Build and use
pixi shell
colcon build --symlink-install
source install/setup.zsh   # or install/setup.bash
